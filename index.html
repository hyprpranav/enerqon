Complete IoT Monitoring Architecture

Engineered for high accuracy AC sampling, safety isolation, real-time telemetry, and enterprise reporting.

⚡

Precise RMS AC Measurement

ESP32 samples AC voltage with LM358 V3 conditioning and AC current with ACS712 Hall-effect sensor at 1 kHz per cycle, calculating accurate True RMS power and power factor.

🔌

Direct Web Serial USB Sync

Zero driver or cloud lag. Connect your ESP32 directly via USB; browser streams high-frequency JSON packets line-by-line via the standard W3C Web Serial API.

💰

Configurable Tariff Engine

Dynamic cost estimation engine with multi-slab utility tariffs, state utility presets, commercial/domestic multipliers, and live bill projection.

📊

Comprehensive Analytics

Hourly load profile, peak vs. off-peak consumption analysis, daily and monthly aggregates, and one-click historical CSV / JSON report exports.

🛡️

Abnormal Load Guard

Rule-based threshold alerts for overvoltage, undervoltage, current surges, and abnormal power spikes with instant visual alarms on user & admin dashboards.

👥

Role-Based Administration

Strict Firebase role-based authorization: dedicated Admin portal for sensor calibration, user verification, grid monitoring, and client telemetry.
